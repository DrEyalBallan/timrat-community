# אפליקציית ברכות לשנה החדשה – קהילת תמרת

אפליקציית ווב מלאה לשיתוף תמונות, ברכות ואיחולים לשנה החדשה עבור קהילת יישוב תמרת (יישוב קהילתי כפרי).

---

## עמודי האפליקציה

### 1. עמוד התושב (`/`)
- הזנת **שם פרטי** ו**שם משפחה**.
- הנחיות ברורות בתיבת הנחיות מעוצבת:
  > **״העלו תמונה וכתבו ברכה לשנה החדשה שקשורה לתמונה״**
- הזנת ברכה אישית לשנה החדשה (שקשורה לתמונה).
- העלאת תמונה עם תצוגה מקדימה (Preview) ומד אחוזי העלאה בזמן אמת.
- מסך אישור חגיגי המציג גלויית ברכה עם התמונה והאיחול.
- אפשרות למחיקה וביטול עצמי של התמונה שהועלתה.

### 2. גלריית צפייה והקרנה בלייב (`/gallery` או `/stream`)
- **מצב מצגת והקרנה (Slideshow)**:
  - תצוגת הקרנה חלקה במסך מלא.
  - שליטה על קצב המעבר בין השקופיות (2 עד 15 שניות).
  - כרטיס ברכה צף על גבי התמונה המציג את **הברכה לשנה החדשה** ואת **שם התושב המברך**.
  - לחצני הרצה (קדימה/אחורה) והשהיה/הפעלה.
- **מצב רשת קהילתית (Community Grid)**:
  - דפדוף בכל הברכות שהועלו על גבי לוח קהילתי.
  - חיפוש מהיר לפי שם תושב או תוכן הברכה.
  - פתיחת חלון מוגדל (Modal) ברזולוציה גבוהה.
- **סנכרון חי (Live Polling)**: כל תמונה שתושב מעלה מתווספת אוטומטית להקרנה תוך 3 שניות ללא צורך בריענון הדף!

### 3. עמוד ניהול אדמין (`/admin`)
- כניסה מאובטחת באמצעות סיסמה (ברירת מחדל: `timrat2025`).
- לוח בקרה מלא: כמות ברכות שהועלו, סינון לפי שם תושב או טקסט.
- מצב סידור מחדש: גרירה ושחרור (Drag & Drop), חצים למעלה/למטה, קפיצה להתחלה/לסוף והזנת מיקום מספרי.
- העלאה מרוכזת (Bulk Upload) של מספר תמונות בו-זמנית.
- מחיקה בודדת ומחיקה מרוכזת של תמונות נבחרות.
- שמירת סדר התצוגה המותאם ישירות לשרת.

- שימוש בלוגו הרשמי של תמרת (`logo.jpeg`).
- צבעי הממשק נגזרו ישירות מהלוגו:
  - **ירוק יער כפרי עמוק**: `#15803d`, `#166534`, `#22c55e`
  - **כתום / טרקוקטה חם של אותיות תמרת**: `#ea580c`, `#f97316`, `#d97706`
  - **זהב וחג**: `#f59e0b`

## הרצה מקומית

```bash
# הפעלת שרת פיתוח
export PATH="$(pwd)/.bin/bin:$(pwd)/node_modules/.bin:$PATH"
next dev -p 3000
```

האפליקציה תרוץ בכתובת: `http://localhost:3000`

## פריסה לייצור (Production)

# בניית הפרויקט
next build

# הפעלת שרת ייצור
next start -p 3000
